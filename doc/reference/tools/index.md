# tools

The functions and types that check, split and print CBOR bytes.

| Function | Does |
|---|---|
| [item_size](item_size.md) | checks the first item and gives its size in bytes |
| [sequence](sequence.md) | gives the items of a CBOR sequence (RFC 8742) one by one |
| [sequence_reader](sequence_reader.md) | gives the items of a CBOR sequence whose bytes arrive in pieces |
| [diagnostic_notation](diagnostic_notation.md) | prints an item as diagnostic notation (RFC 8949 section 8) |
