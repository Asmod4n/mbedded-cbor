cbor::lazy Read a CBOR message in place, step by step.

A lazy is one data item inside a message. It reads only the heads on its way to a value and skips every other item by its length. A text comes back as a view into the message.

at_path

doc.at_path<"$.user.id", std::int64_t>()   → std::expected<std::int64_t, error>
doc.at_path<"$.user.name", std::string_view>() → std::expected<ref<std::string_view>, error>
doc.at_path<"$.user.tags[*]", cbor::nodelist>() → std::expected<nodelist, error>
doc.at_path<"$.user">()                     → std::expected<lazy, error>

Reads the JSONPath (RFC 9535) from this lazy as the root $. Without a type it gives the lazy of the node. A text comes back as a view that holds the message. A path that is not valid does not compile.

Example
doc.at_path<"$.user.id", std::int64_t>() 42

size

doc.size() → std::expected<std::uint64_t, error>

Gives the count of the elements of an array or of the pairs of a map, from the head. A value that is no container gives error::not_indexable.

Example
doc.size() 4

type

doc.type() → std::expected<cbor::type, error>

Gives the type of the data item from its first byte (RFC 8949 3).

Example
doc.type() cbor::type::text_string
